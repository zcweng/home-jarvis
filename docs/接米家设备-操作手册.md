## 1. 五步完成 OAuth（约 3 分钟）

1. 打开 **http://localhost:8123**
2. **设置 → 设备与服务 → 右下角「添加集成」**
3. 搜索框输入 **`Xiaomi Home`** → 点进去
4. 依次填：
   - ✅ 勾选**同意** EULA（小米的许可协议，助手不代为勾选）
   - **地区**：选 **中国大陆**（选错会看不到设备，米家云的数据按地区隔离）
   - **语言**：简体中文
   - **回调地址**：保持默认 `http://localhost:8123`，**不要改**
   - （`network_detect_config` 保持关闭，除非设备用固定 IP 且你懂怎么配）
5. 点**登录** → 会跳转小米账号授权页 → 输入小米账号密码（可能要短信验证）→ **授权**
6. 授权成功后自动回到 HA → 选择**家庭**（有多个家庭时只勾你要控的）→ 设备 → **完成**

> ⚠️ 全程必须用 **`localhost:8123`** 打开 HA。如果你用 `127.0.0.1:8123` 打开的，回调域名对不上，
> 授权完会卡在"正在验证"。真遇到就把地址换成 localhost 重新走一遍。

## 2. 验证接入成功

```bash
cd home-jarvis          # 项目根目录

# ① 实体数量应该明显变多（demo 只有百来个，米家设备通常几十到上百）
.venv/bin/python - <<'EOF'
import re, json, urllib.request
t = open(".env").read()
tok = re.search(r"^HA_TOKEN=(.+)$", t, re.M).group(1).strip()
url = re.search(r"^HA_URL=(.+)$", t, re.M).group(1).strip()
req = urllib.request.Request(url + "/api/states", headers={"Authorization": "Bearer " + tok})
states = json.load(urllib.request.urlopen(req, timeout=15))
print("实体总数:", len(states))
for s in states:
    if s["entity_id"].split(".")[0] in ("light", "switch", "climate", "cover"):
        print(" ", s["entity_id"], "=", s["state"], "|", s["attributes"].get("friendly_name"))
EOF

# ② 看会自动认领哪些设备（不写文件）
.venv/bin/python scripts/gen_aliases.py --dry-run
```

## 4. 移除测试用的 demo 虚拟设备（已完成，附踩坑）

⚠️ **只删 `configuration.yaml` 里的 `demo:` 是不够的**。实测 HA 会把这个 YAML 配置
**自动导入成一个 config entry**（`source: import`），重启后虚拟灯照样在。

正确做法是删掉这个 config entry：

- 界面：**设置 → 设备与服务 → Demo → 右上角 ⋮ → 删除**
- 或调 API（管理员长期令牌）：

```
GET    /api/config/config_entries/entry           # 找到 domain=demo 的 entry_id
DELETE /api/config/config_entries/entry/<entry_id>
```

删完重建别名表：

```bash
.venv/bin/python scripts/gen_aliases.py --rebuild
```

实测效果：实体数 **359 → 260**（demo 的 99 个实体消失）；别名表从 90 条
（混着指示灯/静音/水泵这类噪音）收敛到 **9 台真设备**。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 登录后没有设备 | 地区选错（要选中国大陆）；或该设备只绑在米家 App 的其他小米账号下 |
| 授权后卡在"正在验证" | 回调域名不一致：用 `localhost:8123` 而不是 `127.0.0.1:8123`；或 `internal_url` 被改过 |
| 有一部分设备不出现 | 米家集成**不支持蓝牙、红外、虚拟设备**。纯红外空调/电视需中枢网关或另配方案 |
| 设备出现但只能看不能控 | 该设备米家云未开放写接口；`gen_aliases.py` 生成后手工删掉这条即可 |
| 设备一直 `unavailable` | 常见是**墙上开关关着**（灯类设备靠开关供电，断电后 HA 就看不到它）。把墙开关打开即可恢复；此时助手会如实说"不在线"，不会假装执行 |
| 控制有 0.3~0.8 秒延迟 | 走的是小米云（HTTP 下发）。要更快需装小米中枢网关（≥3.3.0_0023）走本地控制 |
| 助手说"没找到叫 XX 的设备" | 别名表里没有：跑 `gen_aliases.py --dry-run` 看实际名字，或在 `aliases.yaml` 里加 `aliases:` |

## 6. 安全提醒（米家集成特有）

- **小米账号的设备证书与 token 会明文写入** `docker/config/.storage/xiaomi_home.*`
- 因此：Mac 必须开 **FileVault**；`docker/config/` 已在 `.gitignore` 里，别把它推到公开仓库
- **不要把 HA 暴露到公网**，远程访问用 Tailscale
- 米家集成许可：**仅限非商业性 HA 使用**，禁止用于开发 APP / Web 服务。
  自家用没问题；若四象未来要交付客户，必须走米家开放平台企业接入。
