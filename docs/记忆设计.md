# Jarvis 分层记忆设计

## 两层记忆

| 层 | 存什么 | 衰减 | 典型来源 |
|----|--------|------|----------|
| **永久（perm）** | 基础档案、习惯偏好、用户规则、闹钟/提醒事项 | 不衰减 | 「我叫…」「不吃香菜」「以后用您称呼」「3 分钟后提醒关火」 |
| **短期（short）** | 情景摘要、临时约定、长对话压缩 digest | 时间衰减（默认 180 天半衰期）+ 热度 | 对话自动摘要、任务执行片段 |

会话内仍保留 L0 最近 N 轮原文 + L1 最近一次设备操作（见 `jarvis/session.py`），与上述两层正交。

## 架构链路

```
用户输入 → MemoryService.build_context（同步召回）
    ↓
并行：永久臂 + 短期臂 → 打分重排 → token 预算裁剪
    ↓
拼装顺序：永久事实（档案→规则→提醒→偏好）→ 高热度短期 → 近期摘要
    ↓
注入 Session.system_prompt → LLM / 工具
    ↓
回复后 → observe_turn 入队后台：
    分类器 → Writer（冲突纠正 / 合并 / tombstone）
    Digest（episode / 长对话压缩）
```

## 核心组件（`jarvis/memory/`）

1. **store.py** — SQLite WAL：`memories` / `memory_vec` / FTS5 逐字索引 / `turn_log` / `alarms` / `tombstones` / `memory_events`
2. **decay.py** — 半衰期与热度纯函数；召回 `heat += 0.15`
3. **embedding.py** — 本地 ONNX `bge-small-zh-v1.5`；不可用则纯关键词
4. **classifier.py** — 规则快路径 + 可选 LLM JSON
5. **writer.py** — 同槽冲突新值胜出、近似去重、档案槽覆盖、rule 不自动合并
6. **retriever.py** — 双路并行 + score 重排 + 预算
7. **digest.py** — 每 N 轮 episode；超长 history 压缩
8. **alarms.py** — 持久调度，重启补报（`MEMORY_MISSED_GRACE`）；`fired`/`missed`/`cancelled` 保留 `MEMORY_ALARM_RETENTION_DAYS`（默认 7）天后清理
9. **eraser.py** — 语音 / `memory` 工具 / CLI；多条与清空需确认；tombstone 30 天防回写
10. **service.py** — 门面 + 后台队列

## 衰减公式（短期）

```
decay = 2 ** (-Δt_days / half_life_days)   # 默认 half_life=180
heat  = clamp(importance * decay + 0.25 * recall_recency + boost)
```

- 被召回：`heat += 0.15`，刷新 `last_activity_at`
- `heat < 0.08` 且年龄 > 30 天 → 归档（默认不召回）
- 若要「6 小时半衰期」：`.env` 设 `MEMORY_SHORT_HALF_LIFE_DAYS=0.25`

## 冲突纠正示例

1. 「我不喜欢吃苹果」→ `preference` / `food.苹果`
2. 「我现在爱吃苹果了」→ 同 slot 新值写入，旧行 `is_archived=1, superseded_by=新id`
3. 召回渲染标注「（已更新）」时以新值为准（归档旧值默认不召回）

## 配置

见 `.env.example`：`MEMORY_ENABLED`（默认 `false`）及 `MEMORY_DB` / `MEMORY_MODEL_DIR` / `MEMORY_TOKEN_BUDGET` 等。

```bash
uv sync --extra memory
./scripts/fetch_models.sh memory
# .env: MEMORY_ENABLED=true
```


## 验收口径

- 「记住我不吃香菜」→ 重启 → 问饮食相关时 prompt 含该偏好
- 「我现在爱吃苹果了」→ 旧偏好归档
- 「忘掉我不吃香菜」→ 条目删除且 tombstone 阻断回写
- 「3 分钟后提醒我关火」→ 重启后仍会响（在宽限内补报）
- `timer(at=…)` / `repeat=daily|weekly` → 绝对时间与重复提醒；`action=cancel|update|list` 可口语取消/修改/查看
- 已结束提醒（fired/missed/cancelled）保留 7 天后从 `alarms` 表物理删除；不自动删关联 task 记忆
